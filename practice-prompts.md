# ML-DL-NLP Bootcamp — Practice Prompts

## How to Use This File

This repository is my practical learning workspace for the ML-DL-NLP Bootcamp.

My workflow is:

**Learn → Notes → Practice → Code in VS Code/Jupyter → Review → Interview → Quiz → Mini Project → GitHub → Revision → Next Topic**

Use these prompts inside my ChatGPT Project. I should do the implementation myself and use ChatGPT primarily as a teacher, mentor, reviewer, debugger, and interviewer.

---

# Prompt 3 — Practice Coding

```text
I have learned [TOPIC].

Now I want to practice coding in VS Code.

Give me coding problems progressively:

Level 1: 5 beginner problems
Level 2: 5 intermediate problems
Level 3: 3 challenging problems

Do NOT give me solutions initially.

For each problem provide:
- Problem statement
- Input/output expectations
- Constraints
- One or two examples
- What concept I should use

I will solve them in VS Code and send you my code.

When I send my solution, review it instead of immediately replacing it.

First tell me:
1. Whether it works
2. What I did correctly
3. What is wrong
4. Why it is wrong
5. How I can improve it
6. Time complexity
7. Space complexity

Only show the complete corrected solution if necessary.
```

# Prompt 4 — Debug My Code

```text
I am practicing [TOPIC] in VS Code.

Here is my code:

[PASTE CODE]

Do not immediately give me the corrected code.

First:
1. Identify the bug.
2. Explain why it occurs.
3. Give me a hint about how to fix it.
4. Let me try again.

If I still cannot solve it, give me a stronger hint.

Only provide the final solution when I explicitly ask for it.
```

# Prompt 5 — Interview Preparation

```text
I have completed [TOPIC].

Interview me on this topic.

Start with beginner questions and gradually increase the difficulty.

Rules:

- Ask only one question at a time.
- Do not show the answer.
- Wait for my response.
- Evaluate my answer.
- Tell me what I got right.
- Tell me what I missed.
- Give me the ideal interview answer after evaluation.
- Then ask the next question.

Include conceptual, practical, debugging, and coding questions.

At the end, give me:
- Overall score
- Weak areas
- Strong areas
- Topics I should revise
```

# Prompt 10 — Jupyter Notebook Practice

```text
I am practicing [TOPIC] in a Jupyter Notebook.

Help me create a hands-on notebook for this topic.

Structure the notebook as:

1. Title and learning objectives
2. Concept explanation
3. Important syntax/formulas
4. Simple examples
5. Step-by-step code demonstrations
6. Practical examples
7. Exercises for me to solve
8. Challenge problems
9. Common mistakes
10. Key takeaways
11. Interview questions
12. Final mini task

Important rules:

- Do not fill in every exercise with the solution.
- Clearly mark cells where I should write my own code.
- Keep explanations concise enough to be useful inside a notebook.
- Use clean, readable Python.
- Prefer practical examples.
- Include comments only where they improve understanding.
- If the topic involves data, suggest suitable datasets or create small example data where appropriate.

After I complete the notebook, review it and suggest improvements.
```
